## DataSet

we use German Traffic Sign Recognition Benchmark (GTSRB) dataset, 
which contains thousands of images of 43 different kinds of road signs.

you should download it from this URL:
https://cdn.cs50.net/ai/2023/x/projects/5/gtsrb.zip
then put it in this folder (traffic)

## First Attempt

Architecture:
 - Convolutional layer. Learn 32 filters using a 3x3 kernel
 - Max-pooling layer, using 2x2 pool size
 - Flatten units
 - a hidden layer with 128 units and with dropout
 - an output layer with output units for all NUM_CATEGORIES

## Second Attempt

Architecture:
First Convolutional Block:
 - Convolutional layer. Learn 32 filters using a 3x3 kernel
 - Convolutional layer. Learn 32 filters using a 3x3 kernel
 - Max-pooling layer, using 2x2 pool size
 - Dropout Layer with (0.25)

Second Convolutional Block:
 - Convolutional layer. Learn 32 filters using a 3x3 kernel
 - Convolutional layer. Learn 32 filters using a 3x3 kernel
 - Max-pooling layer, using 2x2 pool size
 - Dropout Layer with (0.25)

Classifier:
 - Flatten units
 - a hidden layer with 128 units and with dropout
 - an output layer with output units for all NUM_CATEGORIES

now this structure of layers made the accuracy much more and these are the results:
